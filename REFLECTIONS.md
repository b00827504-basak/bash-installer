# Git Reflection Questions

## 1. Why is version control useful?

Version control saves the history of a project. It helps us see changes and go back to an older version if we make a mistake.

## 2. What is the difference between staging and committing?

Staging means choosing the changes we want to save. Committing saves these changes in the Git history with a message.

## 3. When should you make a commit?

I should make a commit after finishing a small and useful change, for example after adding a file or fixing a problem.

## 4. What is the difference between git init and git clone?

`git init` starts a new Git repository in a folder. `git clone` downloads a copy of an existing repository, including its history.

## 5. Why should you write good commit messages?

Good commit messages explain what changed. They make it easier to understand the project history.

## 6. What is the purpose of using branches?

Branches let us work on new features without changing the main branch. We can merge the work when it is ready.

## 7. When would you create a new branch instead of working on main?

I would create a branch when adding a new feature or testing something. This helps keep the main branch stable.
